# v58 — 기울지 않은 객체의 수직 접촉 후보 누락 수정

2026-10-18. 객체 이름이나 특정 이미지별 규칙은 추가하지 않았다.

`support_seed_assessment`는 `support_translation`으로 유효한 접촉 이동을 구했어도 기울기 후보만 반환했다. 수평 상태로 떠 있는 물체는 기울기 0으로 탈락해, 접촉 가능한 이동을 후속 원본·관통 검사에 전달하지 못했다.

이제 측정된 수직 이동도 후보로 전달한다. 실제 이동 거리는 입력 한계와 객체 대각선의 8% 중 작은 값 이하여야 한다. 이동한 위치에서 유한 표면 접촉을 다시 확인하고, 이후 원본 마스크·가시 깊이·기존 지지·충돌 검사를 모두 통과해야 적용한다. 이미 지지된 객체와 관측 표면이 없는 객체는 기존처럼 건드리지 않는다.

검증에는 수평으로 떠 있는 상자, 허용 이동 초과, 이미 접촉한 물체, 표면 부재, 입력 불변성 및 새 후보가 원본 증거 거부를 우회하지 못하는 통합 검사를 포함했다.

기본 환경 전체 검사: **524 passed, 6 skipped**, 23.96초. 건너뛴 검사를 통과로 간주하지 않는다.

## 실제 장면에 대한 제한

기존 집 v55 및 사무실 v54의 `supported_refinement.json`에서, 접촉 이동이 유효하지만 기울기 후보가 없는 기록을 검색했다. 두 장면 모두 해당 사례는 **0건**이었다. 따라서 이 결함은 일반적인 후보 누락이지만 두 장면의 기존 실패를 해결했다는 증거는 아니다. 새 GPU 제출이나 전체 장면 재생·배포는 하지 않았다. 실제 품질 개선과 7단계 완료는 미확인 상태다.
