# v7 비교 검증 계획과 현재 상태

목표는 기존 7단계 완료 기준이다. 이 문서는 부분 구현을 완료로 바꾸지 않는다. 승인된 GPU 9회 비교는 종료됐으며, 품질 미달로 v7은 미배포이고 운영은 v4로 복원했다. 최종 결과와 단계별 상태는 [GPU 비교 보고서](V7_GPU_COMPARISON.md)를 참고한다.

## 준비된 변경

- 실제 밑부분 정점으로 접촉 위치를 샘플링하고, 받침들의 지지 다각형을 검사한다. 빈 경계 상자 모서리나 중앙에 반드시 표면이 있어야 한다는 조건을 제거했다. 열린 표면의 실제 삼각형에도 수직 교차 검사가 가능하다. 충돌 회피는 여전히 보수적이며 전체 열린 메시 관통 해결은 미완료다.
- 공유 깊이의 표면 법선으로 공간 위쪽 방향을 추정한다. 방향 합의·수직 표면 근거·영상 내 분포가 부족하면 기존 정렬로 돌아간다. 카메라 +Y에서 45도 이내라는 사전 조건이 있고, 독립적인 영상 선분·소실점 검증은 미구현이다.
- 화면 세 가장자리에 걸친 성긴 다중 평면 마스크는 공간 후보로 분리한다. 이름은 검사에 사용하지 않는다. 잘린 개방형 가구를 잘못 분리할 가능성이 있으므로 신뢰도는 확률로 표현하지 않으며 원본 마스크와 근거를 보존한다.
- 부분 중복 검사는 평면뿐 아니라 경계의 깊이·색상·접선 방향이 연속된 곡면을 다룬다. 작은 독립 물체와 깊이 단차는 보존한다.
- 공간 표면의 깊이 불연속을 가로지르는 긴 삼각형을 막는다. 사방에 관측 평면이 있고 실제로 전경이 가린 작은 영역에만 제한적 평면 연장을 허용한다. 창문·이미지 바깥·넓은 미관측 영역은 메우지 않는다. 관측 픽셀과 추정 픽셀을 별도로 기록한다.

## 로컬 검증 결과

테스트 117개, 기존 22장면·120객체의 이름 불변성·재실행 동일성·GLB 재로드 검사를 통과했다. 기존 실패 3장도 원본 해시를 유지한 채 재처리했다. 집·사무실은 넓은 공간 후보 각각 1개를 객체에서 분리하여 12→11개가 됐고, 식당은 12개를 유지했다. 집의 소파 부분 중복, 작은 객체 누락, 지지 관계 문제는 남아 있다. 접촉 보정은 세 장 모두 0건이다. 따라서 **품질 기준 전체 통과가 아니다.**

접촉만 변경 / 방향·공간만 변경 / 조합을 비교한 중간 분석은 `.runtime/v7-validation/`에 있다. 해당 분석은 공간 후보 분리·가림 영역 연장 전 버전으로, 최종 결과와 혼동하지 않는다. 최종 코드 재처리와 원본 해시는 `.runtime/v7-final/`에 기록했다. 합성 검사 통과는 실제 품질의 증명이 아니다.

## 미사용 평가 입력과 기준선

`QUALITY_EVALUATION_V2.json`은 기존 실패 3장을 개발 자료로 옮기고, 고정 공개 revision에서 받은 새로운 실내 입력 3장(창이 있는 방, 진열장, 계단 홀)을 평가용으로 분리한다. 출력 확인 전 선택한 25개 객체의 대략적 2D 상자와 작은 객체 여부를 기록했다. 이는 어시스턴트가 작성한 제한된 부분 주석이며, 독립된 전문가 검수나 정답 3D 데이터가 아니다.

`scripts/evaluate_annotated_run.py`는 입력 파일 해시·정규화 RGB 픽셀 일치를 확인하고 일대일 마스크 상자 대응을 비교한다. 하나의 넓은 마스크로 여러 정답 객체가 모두 검출됐다고 계산하지 않는다. 결과는 선택된 부분의 대응률이며 전체 재현율로 부르지 않는다. 중복·잘못된 이동·지지 관계·공간 구조는 화면 검토가 별도로 필요하다.

계획은 같은 3장을 v4·v5·v7에 각각 실행하는 총 9회다. v4/v5 기준선은 기존 고정 release를 사용한다. v7 패키지는 `.runtime/v7-release/application.zip`, SHA-256 `6be865c6197b71425fe88bc665af5b9d1a6a4527ef5875022709019c6bd1f60b`이다. 2026-10-16 사용자 승인 후 업로드했으며, 동일한 패키지로 비교 검증을 완료했다.

## 외부 실행 범위

2026-10-16 사용자가 위 9회 비교 실행과 임시 적용 후 v4 복원을 승인했다. 승인된 범위 안에서 실행하며 제출 기록은 `.runtime/v7-gpu-comparison/jobs.json`에 보존한다. GPU 사용료가 발생하며 새 GPU 종류·스케일 설정·리소스 생성은 포함하지 않는다. 기존 endpoint에 버전별 release만 임시 적용하고, 각 단계의 작업 종료와 worker 교체를 확인한다. 완료 또는 실패 시 원래 v4 release·env·worker 설정을 복원하여 재조회한다. 재시도나 추가 입력은 자동으로 늘리지 않는다. 웹 운영 버전은 변경하지 않는다.

품질이 미달하면 정식 배포하지 않는다. 결과와 남은 실패 사례를 기록하고 후속 수정에는 다른 미사용 평가 입력을 사용한다. MCP 도구의 조회는 HTTP 403으로 실패했으나, 공식 REST v2 읽기 조회는 성공하여 원래 v4 release와 worker 설정 및 대기/진행 작업 0건을 재확인했다. 이 조회는 실행 전 기록이다. 현재 실행 경과는 `.runtime/v7-gpu-comparison/events.jsonl`에, 최종 복원 확인은 실행 종료 후 `rollback-result.json`에 기록한다.

최종 재처리 3장 모두 Chrome WebGL 표시, 객체·공간·유형별 표시 전환, cutaway, GLB 다운로드 바이트 일치를 통과했다. 보고서는 `.runtime/v7-final/<run>/browser-report.json`에 있다. 읽기 전용 로컬 뷰어는 `http://127.0.0.1:8088/?run=<run>`에서 제공한다. 창·책상·가구 아래 공간의 단절, 소품 누락, 부분 객체 중복은 여전히 품질 실패로 남으며 UI 검증 통과와 구분한다.
