# v57 — 같은 후보의 원본·확장 마스크 검사에서 검색 구조 공유

2026-10-18. 새 GPU 생성이나 배포는 하지 않았다. 기존 검증의 중복 계산을 줄인 변경이며 품질 개선을 입증한 결과는 아니다.

## 변경

`reconstruction_evidence.assess_masks`는 한 후보의 여러 마스크를 검사할 때 메시와 거리·광선 검색 구조를 공유한다. 자세·지지·관통 보정의 원본/현재 마스크 검사에 연결했다. 기존 `assess` API, 샘플 선택, 임계값, 판정은 유지한다. 공유 범위는 함수 호출 한 번이며 다음 변환 후보에는 새 메시를 만든다. 깊이/투영 증거가 부족하면 메시를 만들지 않는다.

## 검증

- 독립 마스크 검사와 공유 검사의 결과 딕셔너리 전체가 정확히 동일함을 일반 거리·가시 깊이 두 모드에서 확인했다.
- 후보 좌표 변경 후 이전 검색 구조가 재사용되지 않는지 확인했다.
- 원본 마스크 악화 시 자세/관통 변경을 거부하는 통합 검사를 유지했다.
- 기본 환경 전체 검사: **521 passed, 6 skipped**, 24.09초. 건너뛴 검사를 통과로 간주하지 않는다.
- 20,480삼각형 합성 장면, 마스크 2개, 가시 깊이 포함: 예열 후 교차 순서 3회 측정 중앙값 독립 **0.81360초**, 공유 **0.74364초**. 약 **8.6% 감소**. 모든 회차의 증거가 정확히 같았다.

측정 스크립트: `.runtime/benchmark_shared_evidence_v57.py`; 원시 결과: `.runtime/benchmark_shared_evidence_v57.json`.

이 작은 측정으로 전체 장면의 속도 개선이나 GPU 2시간 제한 해결을 주장할 수 없다. 지지 관계 성공 사례, 미사용 평가, 인증 브라우저 경로, 배포는 여전히 미완료다. 이전 보고서의 저장 결과 및 동결 코드는 변경하지 않았다.
