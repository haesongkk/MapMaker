수치는 사전에 선택한 객체의 마스크 상자 대응이다. 전체 재현율이나 3D 형상·배치 정확도가 아니다.

전시장 복합 중복 메시 1개가 제거됐다. 독립 자식 마스크가 해당 영역의 99.999% 이상을 유지하고, 자식 메시의 원본 시점 투영도 확인한 경우다. 이름을 판단에 쓰지 않았다. 진열장과 별도 선반의 겹침까지 해결됐다는 뜻은 아니다.

세 결과의 지지 보정 이동은 모두 0건이었다. 전시장에서는 지지면을 찾지 못한 경우 407건, 이동 범위 초과 33건, 높이 불일치 19건 등이 기록됐다. 화면에도 떠 있는 소품과 선반 겹침이 남았다. 검사 수행 자체를 관계 개선으로 세지 않는다.

## 남은 실패와 근거

- **sunroom:** 작은 병과 책이 누락됐다. 병은 확대 영역 두 곳에서 신뢰도 0.66015625와 0.75로 검출됐으나 작은 마스크 기준 0.8에서 제외됐다. 책은 유효 탐지 프롬프트에 없었다. 새 큰 생성 구조물이 공간을 가리는 문제도 남았다.
- **display case:** 선택 소품은 모두 대응됐으나 생성된 지지면과 소품 배치가 맞지 않는다. 추가 평면 진단에서도 지지면을 단일 평면으로 정렬할 근거가 부족했다. 단순 평면화나 이동 제한 완화를 적용하지 않았다.
- **stair hall:** 선택 객체와 작은 객체 대응은 개선됐지만, 관측 공간 패치 1개만으로 바닥·벽·천장이 이어지는 공간을 복원하지 못했다. 일부 건축·조각 부분들이 별도 객체로 남는다.
- **크기·시간:** 최종 GLB는 각각 약 143.1, 241.3, 260.5 MiB다. 성공한 3회 실행 시간 합계는 약 51.6분이며 대기·초기화·실패 실행이나 청구 시간을 모두 포함한 비용 수치는 아니다.

## 실행 오류와 승인 상한

이번 작업 중 구현 실수 2건을 수정했다. 첫 후보는 새 루트 파일의 전송 규칙 불일치를 발견해 취소했다. 두 번째 후보는 함수 추출 뒤 남은 변수 참조로 분할 후 실패했다. 각각 종료 상태와 v4 복원을 확인했고, 실패·취소도 제출 수에 포함했다.

전체 비전 진입점에 GPU 모델만 대체한 테스트, 실제 회수 마스크 후처리 재현, 40개 후보 전송 왕복 검증을 추가했다. 현재 전체 테스트 199개와 미정의 변수 정적 검사가 통과했다. 그 이후 수정 후보의 실제 GPU 3회가 모두 성공했다.

현재 승인 연쇄의 누적 사용은 **8/17회**다: 이전 v8 개발 3회 + 취소 1회 + 실패 1회 + v9r2 개발 3회. 남은 9회는 미사용 평가 3장×3버전이며, 그중 v9 거실 1회를 실제 인증 브라우저 생성과 겸하도록 구성했다. **개발 품질 조건이 충족되지 않아 이 9회는 제출하지 않았다.**

## 다음 수정의 준비 상태

후속 로컬 후보에서는 이름 없이 서로 다른 확대 영역의 마스크 일치를 확인하는 `mask_corroboration.py`를 선택 경로에 연결했다. 원래 점수가 0.6 이상인 작은 후보가 별도 크롭의 관측과 IoU 0.8 이상으로 일치하면 선택 근거를 별도로 기록한다. 점수를 부풀리지 않고 같은 크롭의 별칭 반복은 추가 관측으로 세지 않는다. 단독 관측 기준은 그대로다. 낮은 점수의 검토 가능한 마스크도 전송·보존한다. **이는 동결된 v9r2 GPU 결과 이후의 로컬 변경이며, 실제 누락 개선은 아직 입증되지 않았다.** 기존 실패 배치에서 탈락 마스크 자체를 보존하지 않았으므로 당시 병 두 검출의 일치를 사후 가정하지 않는다.

보정 전 재생은 `scene_replay.py`에서 저장된 개별 자산과 원래 변환으로 복원한다. 제거된 객체까지 복원하며, 현재 버전으로 이미 보정된 입력을 그대로 변경별 비교에 넣으면 오류로 중단하도록 했다. 실제 전시장 원본 29개를 복원하고 기존 보정을 다시 적용한 결과, v9r2의 최종 GLB와 바이트까지 동일했다. 세 개발 장면의 기록된 원래 변환 75개에 대한 CPU 조립 오차는 최대 5.83e-7이었다.

전시장 메시에서 충돌 검사를 이동 경로 대신 최종 위치로 바꾼 읽기 전용 실험도 수행했다. 경로만 원인이었던 거부는 0건이고 지지 이동 역시 0건이었다. 운영 보정 규칙을 완화하지 않았다. 근거는 `.runtime/v10-local/displaycase-endpoint-audit.json`에 있다. 후속 로컬 변경을 포함한 전체 테스트는 204개 통과했다.

지지 문제는 현재 메시에서 단순 이동만으로 해결할 수 있는 경우와 형상 자체가 맞지 않는 경우를 분리해야 한다. 평면 진단은 읽기 전용이며 형상을 바꾸지 않았다. 새 규칙을 특정 이미지의 수치에 맞춰 통과시키거나 실패한 후보로 평가 세트를 소비하지 않는다.
